# 公版经典现代改编长篇

## Overview

把一部公版经典长篇改写为现代背景的小说：保留原著的骨架（主线、双线结构、标志性场景），
重造人物、地理、职业与核心意象，按网络阅读的单章节奏成稿，最后交付成"正文 + 附录"两件套。

判断做得好不好的唯一标准是：**没读过原著的读者能当原创小说读完，读过原著的读者处处认得出来。**

---

## 阶段一：读原著（不可跳过，凭记忆必错）

- 目标仓库若有 `AGENTS.md` / 协作规则文件，动手前先读完。
- 确认版本与结构：部数、章数、主副线、公认的标志性场景。
- 边读边列三张清单：
  1. **转折点清单**：主线每个不可逆的转折（出轨、摊牌、死亡、宽恕、决裂）。
  2. **Icon 清单**：必须保留的标志场景——通常 8–14 个，是读者"认出原著"的锚点。
  3. **可删清单**：议论性章节、次要支线、与主线无关的社会描摹。
- 决定移植目的地：原著的两座城 / 两种价值 → 现代两个城市；田园线 → 乡村或农场。
  例：彼得堡（权力与上流）→ 华盛顿；莫斯科（商业与旧族）→ 纽约；庄园 → 哈德逊河谷农场。

## 阶段二：人物与命名

- 顺序不能反：先定**现代职业与阶层**，再定名字。职业置换示例：
  官僚丈夫 → 参议员 / 集团董事长；军官贵族 → 赛车手 / 家族企业继承人；
  社交名媛 → 沙龙女主人 / 投资人；庄园主 → 返乡创业者；农民 → 农场工人。
- **零原著痕迹**：不得出现近似姓氏、原著语言的小名/爱称、与原著人物相同的首字母缩写。
  - 坑：原著若有用首字母传情的场景（粉笔写字等），缩写必须换成新名字的首字母。
  - 坑：配角的族裔与姓名要自洽（别让乌克兰人叫意大利名，别让美国孩子叫俄语名）。
- 英文命名习惯：两音节名 + 单音节姓，性别中立优先，读起来像真人；不要用单词句柄式网名。
- 房子笔名跨书统一，不按书换名（本账号口径：英文书 `Ellis Wren`，中文书「旧书摊主」）。

## 阶段三：结构设计

- 章数 = 原著部数，不要再拆细。每章一个主场景群，章内用空行或分隔线断句，方便手机阅读。
- 单章长度：中文 ≤ 3,000 字；英文 ≈ 1,800–2,000 词为上限（实测 850–1,700 词读感最好）。
  判断是否需要拆章：先算各章词数，超过等值线再拆，不要凭感觉。
- **开篇第一句**用原著名句的本土化改写；**末章最后一句**回扣开篇意象与名句，形成闭环。

## 阶段四：写法细则

- 原创散文，不复制译本文字。借的是结构与意象，不是句子。
- **元叙述禁令**：正文里不出现"原著里这里是莫斯科""the original was..."
  这类对照说明——读者只需要故事。出处只写在正文副标题行与附录里。
- 意象要贯穿：把原著的核心意象（如火车）同时放进开篇（旁观者的死亡）与结局（主角的死亡）。
- 每章至少留一处现代细节（手机、安检、打车、播客、NDA），让移植落地而不是架空。
- 情绪的处理要克制：死亡、自杀、情欲不渲染细节，写结果与旁人的反应比写过程有力。

## 阶段五：自查（必须人工通读，grep 不够）

grep 只能查出名字残留，查不出逻辑。成稿后从头到尾读一遍，逐项核对：

1. **时间线**：受孕 / 出生月份与前后事件是否冲突；"第几个冬天""几年后"的计数是否与年龄线一致。
2. **地理**：现实交通与场所要对。例：华盛顿到纽约的 Amtrak 到 Penn Station，Metro-North 才在 Grand Central。
3. **年龄**：人物自述年龄与年份推算是否一致（前后跨章最容易错）。
4. **指代**：台词里的"她 / 他 / 你"指谁，读者一次能否读明白。
5. **关系补链**：某人为什么会出现在此处（补一句动机）；某个决定前后矛盾（补一句交代）。
6. **残留**：原著人名 / 地名 / 典故、旧改稿的半截痕迹（"卖火柴——no"这类自我更正句式）。
7. **词汇排版**：缺空格、生造词、大小写不一致。

## 阶段六：成稿与交付

文件两件套，放在**原著目录下、与 `原文/` 平级的项目目录**里
（例：`小说改编/安娜卡列尼娜/GRAND CENTRAL/`；每个改编独占一个目录，不摊在原著目录下）。

**正文 `{书名}.md`**：

```
# 书名

**——改编自XX《XX》的现代XX小说**      # 中文书：现代都市小说；英文书：现代美国小说（英文版）

> 原著名句一（语言随正文）
>
> 原著名句二

---

## 第1章 章名        # 英文书：## Chapter One — Title

（正文）

（全文完）            # 英文书：*THE END*
```

**附录 `{书名}·附录.md`**：

```
# 《书名》附录

（本文件为附录资料，与正文分开；正文见《书名.md》）

---

## 人物表            # 姓名 + 身份与人物关系，一人一行

---

## 后记：改编对照表

| 原著 | 本稿 |     # 场景 / 意象 / 地理对照
| 原著人物 | 本稿人物 |   # 人物对照
（末段）主要删减说明 + 双主题如何分配
```

## 常见错误

- 用 `PART ONE / PART TWO` 分章：网络阅读按 Chapter 走。
- 名字里留原著影子（首字母、语音、小名）。
- 正文里解释改编来源、对比原著。
- 只 grep 不通读：逻辑、地理、时间线的错，grep 一个也查不出来。
- 章数自行加码：跟着原著部数走，改动越多越容易出洞。
