# 竞品分析报告执行模板

# 版本：v1.0
# 更新日期：2026-09-23
# 版本说明：品类/单品竞品分析通用模板，三阶段执行、11章正文+第12节参考资料，输出公众号风格 Markdown。封面由 article-cover-image 技能单独负责，本技能不涉及。

## 模板使用说明

1. 核心参数：仅需传入大写参数【TOPIC】，支持具体单一产品或完整产品品类两类输入，适配全行业ToB/ToC、工具类、AI类、软硬件、数字化服务等所有产品形态。
2. 适配逻辑（核心自适应规则）：
   - 输入【具体单品】（如：剪映PC版、Sora AI视频生成）：以该产品为核心对标主体，全网检索同赛道直接竞品、间接竞品、潜在竞品，做定向竞品对标分析。
   - 输入【产品品类】（如：AI视频生成产品、在线思维导图工具）：自动筛选赛道TOP主流头部竞品、梯队玩家，完成品类全景竞品格局分析。
3. 调研定位：纯竞品导向，区别于产品调研报告，聚焦竞品对标、竞争格局、差异化优劣、市场攻防、机会缺口，适配产品立项、迭代优化、竞品破局、市场竞争、战略复盘场景。
4. 执行规则：严格遵循「信息检索收集→信息清洗结构化→正式报告撰写」三阶段执行，不跳过步骤、不编造数据，全部内容依托近2-3年公开网络最新信息生成。
5. 输出标准：仅输出完整版正式竞品分析报告文档，隐藏所有中间检索、整理过程，内容专业严谨、可直接复制存档、用于职场正式汇报。

## 总任务

针对输入的【TOPIC】，完成一份专业、完整、落地性极强的竞品分析报告。严格按照3个阶段分步执行，不跳过任何一步，所有内容基于公开网络权威信息，禁止编造数据与观点，最终输出完整版正式文档级竞品分析报告。

核心适配规则：若TOPIC为具体产品，以该产品为核心对标主体，挖掘全量上下游、直接/间接竞品；若TOPIC为产品品类，自动筛选赛道主流头部竞品、梯队玩家，开展全景竞品分析。

## 阶段1：信息检索与竞品原始资料全方位收集（竞品分析专属）

目标：围绕【TOPIC】，全覆盖检索所有相关竞品信息，聚焦竞品维度，摒弃无效的单品冗余信息，保证对标维度完整、素材最新、来源可信。

1. 自动生成多组差异化搜索关键词，全覆盖竞品核心调研维度：竞品清单、竞品梯队划分、竞品核心功能、产品形态、定价体系、盈利模式、渠道策略、目标用户、核心技术壁垒、用户口碑、优势短板、迭代动态、市场份额、渗透率、落地场景、最新版本更新、运营策略、营销打法、政策合规情况、用户痛点、差评槽点、行业测评对比、差异化亮点、市场竞争策略、潜在入局玩家、赛道竞争风险与机遇。
2. 依托关键词检索公开网络信息，广泛收集原始竞品素材，包含：多竞品横向对比数据、各竞品功能参数、定价套餐、用户评价、专业测评报告、市场份额数据、官方迭代公告、营销活动案例、落地客户案例、行业机构竞争分析、用户吐槽与核心痛点。来源覆盖产品官网、权威测评平台、行业白皮书、券商研报、科技媒体、用户社区、行业论坛，保证来源多元、真实可信。
3. 信息分层标记：严格区分客观事实数据、行业测评观点、市场用户口碑、网络传闻，标注信息时效性，优先选用近2-3年最新数据与动态，老旧信息仅用于历史溯源，不作为核心分析依据。
4. 完整汇总所有竞品原始素材，保留核心对标细节、关键数据、差异化特征，不删减关键信息、不提前加工润色，完整留存全部调研素材。

## 阶段2：信息分析、清洗与竞品结构化整理（竞品分析专属）

基于阶段1原始素材，聚焦竞品对标、竞争格局、差异化差异完成标准化加工整理：

1. 去重提纯：删除重复、无效、模糊、来源不可信、过期失效信息，仅保留有效竞品对标素材。
2. 数据校验：核对各竞品的功能参数、定价、市场数据、用户数据、迭代信息，识别多来源冲突数据，标注口径差异、数据偏差及来源区别，保证对标数据准确。
3. 结构化归类：将有效信息按照标准竞品分析报告框架分层归档，核心模块包含：赛道竞争全景、竞品梯队划分、头部竞品详细拆解、多维度横向对标、各竞品SWOT分析、用户心智与口碑差异、竞品打法与策略、市场差异化缺口、竞争风险与机会。
4. 核心提炼：萃取关键对标数据、竞品核心优劣势、差异化亮点、用户核心痛点、赛道空白机会、竞品短板漏洞，搭建完整竞品分析素材库，支撑正式报告撰稿。

## 阶段3：撰写正式竞品分析报告（固定通用目录+硬性写作规范）

基于结构化素材撰写完整版正式竞品分析报告，文风专业严谨、逻辑清晰、落地性强，适配企业产品竞争分析、迭代优化、市场破局、战略决策、汇报存档场景，严格遵循以下固定目录与写作要求。

### 固定通用报告目录（全产品适配）

1. 竞品调研摘要（核心竞争结论、调研范围、核心对标发现、核心机会与风险浓缩）
2. 调研概述（调研背景、对标维度、调研方法、数据时效、适配场景说明）
3. 赛道整体竞争格局（品类全景）
   - 3.1 赛道整体竞争现状与市场集中度
   - 3.2 竞品梯队分层划分（头部、腰部、长尾、潜在入局者）
   - 3.3 整体竞争核心特征与行业竞争趋势
4. 核心竞品基础信息深度拆解
   - 4.1 各核心竞品产品定位、核心赛道、目标人群
   - 4.2 各竞品发展历程、当前迭代阶段、市场布局
   - 4.3 各竞品核心技术壁垒、核心产品主打优势
5. 多维度竞品横向对标分析（核心章节）
   - 5.1 核心功能模块对标对比
   - 5.2 产品定价、套餐体系、盈利模式对标
   - 5.3 应用场景、落地能力对标
   - 5.4 渠道分发、营销运营打法对标
   - 5.5 用户口碑、核心优势、核心痛点差评对标
6. 头部竞品独立SWOT分析（逐一对标拆解）
   - 6.1 每款头部竞品优势（S）、劣势（W）、市场机会（O）、竞争威胁（T）
   - 6.2 各竞品核心竞争打法与核心护城河
7. 市场差异化与竞争缺口分析
   - 7.1 现有竞品同质化问题汇总
   - 7.2 赛道未被满足的用户需求与功能缺口
   - 7.3 各竞品短板漏洞与可突破切入点
8. 整体市场竞争风险与挑战
   - 8.1 头部竞品压制风险、赛道内卷风险
   - 8.2 技术迭代、政策合规、用户留存竞争风险
   - 8.3 新入局玩家冲击风险
9. 未来赛道竞争趋势预判
   - 9.1 产品功能迭代竞争趋势
   - 9.2 市场运营与渠道竞争趋势
   - 9.3 差异化竞争发展方向
10. 竞品应对落地策略与优化建议（核心落地输出）
    - 10.1 产品功能差异化破局建议
    - 10.2 市场与运营对标突围策略
    - 10.3 竞品短板针对性卡位方案
    - 10.4 风险规避与长期竞争布局建议
11. 全文调研总结
12. 参考资料（按引用顺序或主题归类，列出正文实际引用的主要来源；有公开 URL 的附链接，无可靠链接的只写来源名称；只列正文真正引用过的，不堆砌、不编造）

### 统一写作硬性要求

1. 全文以竞品对标、竞争分析为核心，弱化单品无关冗余内容，所有内容基于公开调研素材，绝不凭空编造数据、观点、案例；多口径冲突数据需明确标注数据来源、口径差异及偏差原因。
2. 行文正式专业、段落分层清晰，多使用对比式表述，专业术语辅以通俗阐释，做到专业不晦涩、易懂且严谨。
3. 所有关键对标数据、用户案例、竞品观点、行业结论，统一标注来源类型（权威行业报告、媒体公开资讯、产品官方公告、用户调研数据、专业测评平台等）。
4. 优先使用表格、清单呈现多竞品横向对比内容，对标差异直观清晰，提升报告实用性。
5. 最终仅输出完整报告正文成品，可直接复制粘贴存档、汇报使用，不输出任何中间检索、素材整理、思考过程内容。

## 输出格式

- 直接输出公众号文章正文，带标题、分段、小标题。
- 输出到文档里，除了文章内容，不要输出多余的头尾。
- 文末在正文参考资料之后另起一行，附适合公众号的话题标签。
- 输出格式为 md 文档，禁止输出 word doc/docx 等格式。
- 若 md 格式有 markdown 加粗片段，加粗片段开头、结尾处不要包含标点符号，如禁止加粗片段以 '：、。' 等开头、结尾。
