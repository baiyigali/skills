# Policy Interpretation Writing Skill

政策/法律深度解读文章写作技能，用于生成公众号风格的深度政策解读文章。

## 这是什么？

这是一个 AI Agent 技能（Skill），帮助你写出**有深度、有观点、有背景**的政策解读文章，而不是简单的政策条文复述。

## 核心特点

- **深度解读**：不是把政策原文换个说法再说一遍，而是讲清楚"这意味着什么"
- **自动选题**：通过网络搜索发现最新政策热点
- **叙事风格**：参考《经济学人》《晚点LatePost》《三联生活周刊》的深度报道风格
- **实用导向**：告诉读者"我该怎么办"

## 文章结构

1. **标题**：准确概括政策变化与实际影响，不做标题党
2. **引言**：从场景/现象切入，抛出问题
3. **背景与变化**：为什么现在出这个政策？之前是什么样的？
4. **核心变化**：挑1-2个最关键的点深入讲透
5. **实际影响**：对普通人/企业有什么影响？
6. **实操指引**：现在该怎么办？
7. **结尾**：有观点、有思考
8. **封面**：正文落盘后调用 `article-cover-image` 技能生成，本地相对路径引用

封面环节依赖 `article-cover-image` 技能（同一仓库）。未安装时写作技能会提示安装，紧急情况下走内联简版规则。

## 适用场景

- 需要解读最新出台的政策、法律法规
- 需要写公众号风格的深度评论文章
- 需要把枯燥的政策文件写成普通人能看懂的文章

## 使用方式

在 AI Agent（如 Doubao）中加载此技能，然后说：
- "帮我写一篇关于XX政策的深度解读"
- "最近有什么值得写的政策热点？"
- "解读一下这个新出台的文件"

## 写作原则

1. **深度优先**：宁可把1个点讲透，也不要把10个点都讲得很表面
2. **有观点**：不是客观陈述，而是有自己的分析和判断
3. **有背景**：必须讲清楚政策出台的背景和变化
4. **不编造**：所有解读基于政策原文和公开资料
5. **实用导向**：读者看完要知道"我该怎么办"
