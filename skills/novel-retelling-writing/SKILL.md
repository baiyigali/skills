# 经典小说现代改编（Retelling）写作流程

背景锚点：本项目把托尔斯泰《安娜·卡列尼娜》（Garnett 英译全本，8 部 239 章，约 200 万字符）改写成约 2.3 万字的现代都市小说《她的名字叫安澜》，全程一稿过审。本技能沉淀其方法论与坑。

## 0. 铁律

- **动笔前必须逐项确认**：改编规模、写作语言、背景城市（真实城市 vs 架构双城）。三个都问清再写，返工代价极高。
- **人物名零音译影子**：不能出现"卡宁""沃伦"这类假中国名；用户会逐一揪。
- **家族树必须符合中国传统姓氏规矩**：女儿随娘家姓、子女随生父姓、兄妹同姓。写完专门审一遍。
- **先读仓库/工作区的协作规则文件**（AGENTS.md 等）再动任何既有内容。

## 1. 改编前三问（AskUserQuestion）

| 问题 | 选项参考 | 本项目答案 |
|---|---|---|
| 规模 | 精缩长篇（3-5万字）/ 中篇（<1万）/ 大纲+样章 | 精缩长篇 |
| 语言 | 中文 / 英文 / 双版 | 中文 |
| 背景 | 上海 / 北京 / 架构城市 | 架构双城（澜城=彼得堡、临州=莫斯科） |

经验：架构城市最省心，没有真实地名约束；"权力+上流"与"商业+旧族"双城分工直接映射原著双城气质。

## 2. 原著解构（动笔前完成）

1. **人物映射表**：主角/配角全部列出新名字与身份移植（贵族→董事长/名媛，地主→返乡农业创业者，军官→赛车手等）。身份移植的原则是**保留人物的社会功能**：渥伦斯基的功能是"上流圈最有魅力的危险情人"，现代对应就是职业赛车手。
2. **标志性场景清单**：列出原著名场面并给出现代对应（赛马→赛车大奖赛、割草→暴雨抢收、县选举→行业协会换届、铁路卧轨→货运小站）。这张表写成后记的"改编对照表"，本身就是交付物的一部分。
3. **结构与主题**：双线结构（毁灭线+觉醒线）必须原样保留，结尾两线汇合点要提前设计。

## 3. 人名中国化（最易翻车，专项审查）

- 取名思路：音译改名要"似是而非又完全中文"（基蒂→澄澄、列文→李原）；家族内成对取名有彩蛋（兄妹安朗/安澜、兄弟李峥/李原）。
- **批量替换用脚本**，顺序：长词先替换（如"卡太太"先于"卡"）；替换后 grep 残留，注意误伤（"安娜"全替换会毁掉书名里的"安澜·卡列尼娜"，欧洲/欧巴等含"欧"词要排除）。
- **家族树终审清单**（本项目实际抓出两处错误）：
  - 出嫁女随娘家姓（"杜丽"是谢家女儿却姓杜 → 谢棠）；
  - 子女随**生父**姓（安澜与傅野之女误随继父姓康 → 傅念，随生父姓，讽刺感反而更强）；
  - 长辈称谓别错辈（祖母不能自称"咱家的孙女"→"闺女"）。
- 亲戚称谓链（小姑子/姐夫/娘家/外甥）逐一核对。

## 4. 写作节奏（手机阅读口径）

- **每章 2000-3000 汉字**（≤3000 硬上限），先按段落场景测量再切，切点选在**悬念位**（下一章开场即新场景）。
- 章节命名用"**第N章 章名**"（文学化章名如"火羽号""宽恕"），不要"部一""上卷"这类老派写法——用户明确否决过。
- 初稿难免章节失衡（本项目初稿第1章 4500 字），收尾阶段按场景边界重切，总字数不动。
- 开篇致敬：把原著第一句现代化改写（"幸福的家庭都是相似的"→"幸福的企业都是相似的"），立刻立住改编身份。

## 5. 成稿自检（脚本化，必做）

```bash
# 1. 汉字数统计（分章+合计）
python3 -c "import re; t=open('书.md').read(); print(len(re.findall(r'[\u4e00-\u9fff]',t)))"
```

- **残留英文碎片**：多轮 Edit 产出里常混入起草时的英文词（本项目抓到 second/atleast/fair/看les），`grep -E "[a-zA-Z]{4,}"` 过一遍正文（专有名词除外）。
- **残留哨兵**：分阶段写作用 `<!-- NEXT -->` 占位时，收尾必须确认已全部清除。
- **重复场景**：多次 Edit 修补可能造成同一场戏两个版本并存，对关键句 grep 计数。
- **全角/半角引号混用**、多余空格（"用 完 全"）脚本清洗。

## 6. 交付结构

- **正文与附录分离**：正文文件只含书名、题记、章节；人物表、改编对照表、人名对照表全部拆到《书名·附录.md》——用户明确要求，阅读不被资料打断。
- 文件名跟书名走（书名改了文件同步改名，附录内交叉引用同步更新）。

## 7. 坑清单（本项目实测踩过）

1. 人名替换不排长词顺序 → "卡宁"把"卡太太"切成碎片。
2. 家族树两处姓错（出嫁女、随继父姓）→ 用户抓的，必须主动终审。
3. "部一"式章节名被否 → 用"第N章 章名"。
4. 第1章超长（4500字）→ 按场景边界拆章，切点放悬念位。
5. 附录混在正文里 → 拆文件。
6. 起草英文碎片残留 → 收尾脚本清洗。
7. 原著书名被人名批量替换误伤 → 替换表跑完先 grep 书名/关键词。
